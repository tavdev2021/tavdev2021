Actualmente estoy concentrando todo mi esfuerzo de ingeniería en el diseño y construcción de un ecosistema móvil de producción real:

* **AquaLogix (Ecosistema Multi-Módulo de Logística de Reparto):** Un sistema compuesto por dos aplicaciones nativas independientes en Android (`:app-delivery` y `:app-admin`) que comparten un núcleo de datos.
